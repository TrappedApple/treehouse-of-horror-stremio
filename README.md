# The Simpsons: Treehouse of Horror — Stremio catalogue

A small static Stremio metadata addon that presents the annual Treehouse of Horror specials as one curated series.

## Install URL

https://raw.githubusercontent.com/TrappedApple/treehouse-of-horror-stremio/main/manifest.json

## Catalogue

- Type: `series`
- Catalogue ID: `treehouse-of-horror`
- Series ID: `treehouseofhorror`

The collection uses the real Simpsons episode stream IDs (`tt0096697:season:episode`) so compatible stream addons can resolve the selected episode.
